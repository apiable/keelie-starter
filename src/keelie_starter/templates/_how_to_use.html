How to use a credential

Your code gets a token with OAuth 2.0 client_credentials. It sends the client ID and secret with HTTP Basic auth, to:

{{ token.token_endpoint }}

Every token is for {{ token.resource }}. You may send that address as resource; any other value is refused. What a token allows: {% for scope in subscription.scopes %}{{ scope }}{% if not loop.last %}, {% endif %}{% endfor %}.

TOKEN=$(curl -s -u "YOUR_CLIENT_ID:YOUR_CLIENT_SECRET" \
  -d grant_type=client_credentials \
  {{ token.token_endpoint }} | jq -r .access_token)

curl -s -H "Authorization: Bearer $TOKEN" \
  "{{ settings.api_base_url.rstrip('/') or token.resource }}{{ settings.api_example_path }}" | jq

A token lasts the number of seconds in its expires_in field. Get a new one before it runs out.
